# oneMK 1.1.1: the wallpaper shows on a Mac, and a clearer permission guide

## What is new

- **The picture or video wallpaper now shows on a Mac.** The wallpaper player ran as a background-only program, and macOS never puts the windows of such a program on screen, so the picture was applied inside oneMK but the desktop stayed as it was. The player now runs as a menu-less helper (no Dock icon), which macOS shows. Tested on a real Mac with a picture; a video has not been tried on a real Mac yet.
- **The permission guide says what to try when the switch is already on.** macOS can show oneMK's switch as on for an entry made by an older version of the app and still refuse it. After about 25 seconds on a step, the card now says "Already on? Remove it (−), reopen oneMK".
- **An update no longer leaves its staging folder behind.** A hidden folder with the oldest app in it could stay in Applications after an update; it is now removed once the new window runs.

Nothing about pairing, sharing or the service changed.
