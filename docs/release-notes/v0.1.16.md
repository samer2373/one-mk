# one·mk 0.1.16 — audit fixes

A fix-only release after a fresh independent audit of every 0.1.15 feature, with
each side's fixes reviewed by the other. Nothing new to configure.

## Fixes

- **Settings keep unknown wallpaper tables.** A newer settings file's wallpaper
  table is no longer dropped when an older build saves an unrelated change. A
  `[wallpaper]` section with an unknown key is still ignored as a whole and fails
  closed (wallpaper stays off).
- **Settings files are size-limited.** The daemon and the window refuse a
  `settings.toml` over 4 MiB instead of reading it whole, and say so.
- **Clipboard history in the window.** A non-empty history now displays and
  works. A damaged saved history shows a red error in the History panel, and in
  `one-mk status`, instead of "No clipboard items yet".
- **Latency benchmark** no longer panics on a hostile peer timestamp.
- **Packaging check** no longer accepts a window `--help` that prints usage and
  then fails.
- **Reviews of the unreleased wallpaper work** fixed an odd-height video
  padding bug, a shutdown hang on an incomplete worker header, and a revocation
  that a quick disable/re-enable could hide from a running renderer. These ship
  only as internal code; see below.

## Not in this release

- **There is still no live wallpaper.** Wallpaper policy and the importer remain
  experimental and off by default. The GNOME presenter plays imported media only
  in a private laboratory build, which the release workflow refuses to ship.
- **Typing characters that are not on the receiving keyboard layout** stays off.
  On X11 the key-remap approach was measured to lose characters (50 of 50 strict
  runs failed), so it is not enabled.
- Windows and macOS native behaviour, and real-hardware wallpaper tests, are
  still unverified.
