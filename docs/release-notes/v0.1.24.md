# oneMK 0.1.24: update from inside the app

## New

- **Check for updates, and install, from the window.** Settings > Updates (now
  the first card) has a **Check for updates** button. When a newer version
  exists the same button becomes **Update to VERSION**: it downloads, checks the
  signature, installs and restarts oneMK by itself. No terminal.
- **Linux package (.deb) installs update from the window too.** The system
  asks for your password once (its own dialog), and oneMK installs the signed
  package and restarts. Cancelling changes nothing. Updating without asking
  stays off for packages, because it needs your password.

## Better to diagnose

- The log now says why a paired computer can't be reached (the first failure,
  then once every ten minutes), instead of only showing it as offline.

## Note

The button comes with this version, so each computer needs this one update the
old way: on a Mac, **Update now** in the window; on a Linux package, install the
`.deb` from the release page once. After that, updates are done from the window.
