# oneMK 1.3.0: any key, any button, and your computer's own shortcuts

This release lets you change keys and mouse buttons that the window doesn't draw, adds actions such as Mission Control and switching desktops, and replaces the long action list with a search. Nothing about pairing, the update key or the update format changed.

## What is new

- **Detect a key or a button.** On the Keys and Mouse pages, click **Detect key** or **Detect button** and press it. That works for a macro key, a media key, `F13` and above, a key with no name, or a mouse's side and extra buttons. Its settings open so you can change what it does. When oneMK can tell which keyboard or mouse you used, you can make the change for that one device only. From a terminal: `one-mk input-devices detect`.
- **System actions.** Keys, mouse buttons and swipe gestures can do about 30 things your computer has shortcuts for:
  - next or previous desktop, Mission Control or Task View, and app windows
  - show desktop, Spotlight or search, and the app launcher
  - screenshots, lock screen, force quit, full screen, and the emoji picker
  - switch, hide, close or quit an app
  - copy, paste, undo, find, and tabs

  Each action sends the right shortcut for the computer that receives it, Mac, Windows or Linux, even with Ctrl and Cmd swapped. In rules they are written `os:NAME`, for example `one-mk buttons map 4 os:next-desktop`.
- **An easier action list.** Choosing what a key or button does opens a search instead of a long list. Typing "spaces", "screenshot" or even "mision control" with a typo finds the right action. There are category tabs, and arrow keys and Enter work. Each row shows the shortcut it will send, and an action that does nothing on one of your computers says so before you save it.

## Please note

- On macOS, the desktop and Mission Control actions use Apple's default shortcuts (**System Settings → Keyboard → Keyboard Shortcuts → Mission Control**). If you changed those, the actions follow the defaults, not your changes.
- Mouse buttons 6 to 8 are detected on Mac and Windows but can't be changed there yet.
- On GNOME and KDE (Wayland), while the pointer is on that computer, oneMK sees only the keys you press in its own window, so detection works best from another computer or for keys the window receives.
- The Windows and Mac changes were built and tested, but not yet run on real Windows and Mac computers. If detection or an action behaves differently there, please tell us.
