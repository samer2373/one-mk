# oneMK 1.2.1: a locked screen, safer installs, and a lot more testing

## What is new

- **A locked screen no longer lets the pointer cross to another computer.** While this computer is locked, the edge no longer switches, and a request to enter it is answered "busy" instead of being half-accepted. A switch that was waiting when the lock came is dropped.
- **Installing is safer.** `install.sh` refuses a correctly signed but older release (someone replaying an old download) and a version older than the one already installed. `ONE_MK_ALLOW_OLDER=1` installs an older release on purpose, and `ONE_MK_MAX_AGE_DAYS=N` can also refuse a release published more than N days ago.
- **The .deb names the libraries it needs**, so it installs with its dependencies on a plain Ubuntu or Debian system.
- **Pairing no longer loses a computer on a bad moment.** A pairing is saved before the first connection is tried, and a damaged or half-written identity file is replaced instead of failing every start. A fingerprint is accepted only as plain hexadecimal.
- **Sending folders and files is steadier.** Two folders with the same name are numbered instead of overwriting each other, and a full disk stops the transfer with a clear message.
- **Windows and Mac keys.** The Windows service passes typed characters and text correctly, and the Mac keypad comma on a Japanese keyboard works.
- **The window:** the toolbar wraps on a narrow window, the command palette no longer crashes on some non-English text, the permission guide shows "Open guide" as soon as a permission goes missing, and a flood of messages no longer piles up on screen.
- **Smaller fixes:** a clipboard with an empty format no longer breaks pasting, a GIF wallpaper with a zero frame delay plays at a normal speed, a stale temporary wallpaper file is cleaned up, and an unknown setting in the file is reported once.

This release is also covered by about 500 new automated tests (the window, the daemon on a private network, packaging and the website on nine phone, tablet and desktop profiles); each fix above has a test.

Nothing about the update signing key or the update format changed.
