## What's new in 0.1.13

A big release. Everything below was built and tested on Linux, and each piece was
reviewed by a second model. **Windows, macOS, wlroots compositors (Sway,
Hyprland) and the new packaging jobs have not been run on real hardware or in CI
yet** (see "Not tested yet"); please report anything odd.

### Setup and diagnosis
- `one-mk doctor` checks the program, port, discovery, firewall, desktop
  permissions and each paired computer, and prints a fix for every problem.
- Pair without sitting at both computers: `one-mk invite` prints a one-time link
  and QR code, `one-mk join` accepts it. Both sides compare a 6-digit code.
- Updating from the command line is not in this release (planned).

### Sharing
- Clipboard: choose which formats are shared and a size limit
  (`one-mk clipboard`), send your clipboard to one computer (`clip-send`),
  or fetch another's (`clip-get`).
- Notifications and live progress for received files; `one-mk status` shows
  transfers in flight.
- Drop files on a screen edge that leads to another computer to send them
  (X11; Windows and macOS untested; not possible on GNOME/KDE Wayland).

### Control
- `one-mk switch <computer>|next|here`, `lock-pointer`, and global hotkeys
  (Ctrl+Alt+1..9, next, lock, back here).
- Edge rules: dead corners, a dwell time, a modifier key to cross, a fullscreen
  guard. Gaming mode (relative motion). Lock sync and `lock-all`. Sleep and
  screensaver sync. Media keys. Commands to run when the pointer enters or
  leaves (`one-mk hooks`).
- A pointer drawn on a computer that has no mouse attached.
- Layout profiles that switch by network; a warning when two computers' screens
  don't touch; simultaneous layout changes on two computers now converge.

### Keys and mouse
- A key mapper for any key: remaps, combos, tap/hold, layers, actions, per
  computer, per OS or per app (the app focused on the computer you type into).
- Pointer speed, scroll direction and speed, button remaps (side buttons as
  back/forward). A "Keys & mouse" tab in the window edits all of it, with a
  "Test it" box.

### Linux
- New X11 and wlroots (Sway, Hyprland, labwc) backends next to the GNOME/KDE
  portal one. Permission is remembered across restarts and a lost session
  recovers by itself.

### Window and tray
- Desk, Layout, Clipboard & files, Health, Advanced and Keys & mouse tabs; the
  tray gets switch, clipboard and lock entries and a transfer line.

### Packaging
- The .deb now ships the hidden desktop entry the keyboard-shortcut portal
  needs. New in this release's workflow: an AppImage, and Homebrew and Flatpak
  files; "Send to <computer>" file-manager entries (`one-mk integrate`).

### Changed behaviour
- **Fetching another computer's clipboard (`clip-get`) is off by default.** Turn
  it on on the computer whose clipboard should be readable:
  `one-mk clipboard --allow-fetch on`. `clip-send` and the clipboard following
  the pointer work as before.
- Commands in `[hooks]` and key rules that run programs are refused when
  `settings.toml` is writable by anyone but you.

### Not tested yet
- Windows and macOS behaviour of the features above (compiled and unit-tested
  only), wlroots (no compositor was available), Bluetooth and real tray hosts,
  and the new AppImage/Flatpak/Homebrew jobs.
- Not available on GNOME/KDE Wayland by design of those desktops: per-app rules
  for native windows, dropping files on an edge, and drawing a pointer when no
  mouse is attached.
- Local-only key remapping (keys you type on this computer) is stored but not
  active yet. Turning mouse acceleration off is not possible yet.
