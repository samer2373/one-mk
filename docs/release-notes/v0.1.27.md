# oneMK 0.1.27: a clearer interface with working 3D zoom and precise arrangements

## Improved

- Refined spacing, contrast, focus indicators, and controls throughout the native window, with clearer connection states and recovery actions.
- Compact windows keep key editors, transfer controls, profiles, and computer menus usable. Computer menus show full names, connection states, and the selected computer.
- Real 3D keyboards, mice, and monitors remain interactive, with animated zoom, selection glides, drag rotation, and return to overview. Mouse callouts stay in place while the model turns.

## Fixed

- Selecting a keyboard key now starts its zoom transition automatically. Choose **Whole board** to zoom back out.
- Precisely arranged computers no longer move apart after you release them. Automatic spacing preserves saved and in-progress placements, including two-computer setups with five or more monitors.
- Brand-token exports match the window's current colours, including shared colour constants.

Workspace tests and Clippy passed on Linux, Windows, and macOS before the design PR was merged. Native interaction captures were checked on Linux; hardware frame pacing and real screen-reader interaction have not been qualified.
