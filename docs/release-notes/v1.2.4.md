# oneMK 1.2.4: fewer rough edges

This release fixes a long list of bugs found by reading the whole program line by line, from window crashes to settings that were lost, rules that stopped working and features that failed without saying so. Nothing about pairing, the update key or the update format changed.

## What is fixed

- **The window no longer crashes** when a computer is removed while you drag on the Desk page, when a small monitor sits in a large wall, or when a wallpaper title ends in spaces.
- **Your settings and pairings are safer.**
  - A passing read error on the identity file no longer creates a new identity, which would have made every paired computer stop trusting this one.
  - A typo in settings.toml no longer stops you from unpairing a computer or from saving the emergency "local rules off".
  - Saving any setting no longer drops fields that a newer version added inside your rules.
  - A failed update on a Mac keeps the "Go back" copy of the previous app, and an interrupted settings move on Windows no longer strands the rest of your settings.
- **Key and mouse rules hold up.** One invalid rule used to switch off all the key rules for a computer, and now only that rule is skipped, with a warning. Scroll modifiers now apply to a mouse wheel and a touchpad separately, and changing "Works in" on a rule can no longer delete it.
- **Things that failed silently now work or say why.**
  - The Linux Wi-Fi watcher now sees network changes.
  - Edge crossing on the Wayland portal retries after a failed update.
  - Turning off "Start at login" no longer stops the running service.
  - Files dropped on some pages were sent twice.
  - A clipboard copy that failed to save on the other computer was reported as delivered.
  - The live wallpaper's clock no longer drifts after a reconnect.
- **Files and clipboard.** A busy or changed file no longer ends the rest of a batch as "connection lost". A received file is flushed to disk before it is reported saved, and a clean-up in another folder can no longer delete a file that is still arriving. A password-manager copy from another computer is never passed on to a third one. Clipboard history rows can no longer point at the wrong item after the service restarts.
- **Pointer, keys and drops.** If the packet that switches mouse mode is lost, the first movement is no longer dropped. On wlroots Wayland desktops, edge rules now see the modifier keys that were held when the pointer crossed. File drops from the strip at the screen edge work for a real drag only, and not for a click.
- **Windows and Mac.** The low-level keyboard and mouse hooks are put back after Windows removes them while you were idle, device probing no longer blocks them, the desktop wallpaper comes back after Explorer restarts, and a Mac's Caps Lock state is read before a Caps Lock press.
- **Smaller things.** Many messages and settings pages now say what is true: the Health page, update buttons, the permission guide, the pairing screen and the installer's uninstall step. `one-mk scroll` gains `--clear-natural` and `--modifier MOD=off`.

## Please note

The Windows and Mac changes were built and tested, but not yet run on real Windows and Mac computers. If keys, the pointer, wallpapers or file dropping feel any different there, please tell us.

A few rare cases are still open and are listed in the project notes: two computers dialling each other at the same instant can briefly show different pairing codes (nothing is paired when that happens), and an update can still proceed when the installed copy cannot report its version, so a broken install can be repaired.
