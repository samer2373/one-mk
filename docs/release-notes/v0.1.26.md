# oneMK 0.1.26: the Mac app can update itself

## Fixed

- **"The update didn't finish: the app's security check failed" on the Mac.**
  The check that confirms an update comes from the same publisher asked
  `codesign` for its requirement in a form it reads as a file name, so it
  failed for every update, even a genuine one, and nothing was ever replaced.
  It now asks the right way. If a check still fails, the message names which
  app failed and the reason is written to the log.

Because the old version can't install this one, install 0.1.26 once by hand on
the Mac (open the disk image and drag oneMK to Applications). Updates from
then on happen inside the app.
