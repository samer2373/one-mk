## What's new in 0.1.14

- **Windows computers accept connections over IPv4.** The listener used an
  IPv6-only socket on Windows, so a Windows computer could not be reached by
  address on an ordinary IPv4 network. It now takes both.
- **macOS: no half-second freeze when the pointer comes back.** macOS ignores the
  mouse for a quarter of a second after the pointer is moved onto the Mac; that
  is switched off, so the pointer follows your hand straight away on return.
  (Fix for a reported pause at the crossing; please say if it is still there.)
- All automated tests now pass on Linux, macOS and Windows.
