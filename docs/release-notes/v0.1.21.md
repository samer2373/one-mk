# oneMK 0.1.21: live wallpaper on Wayland

## New

- **Video and picture wallpaper on KDE Plasma, Sway, Hyprland and other
  Wayland desktops.** oneMK checks which desktop you're on and draws the
  wallpaper behind your windows itself, on every screen. It stops using the
  processor while paused.
- **Video wallpaper on GNOME (Wayland), with a small Shell extension.**
  Wallpaper (⌘2) offers to install it. Log out and back in, then turn it on.
  The extension only shows windows from the oneMK player that you started,
  and nothing else. Without it, GNOME still shows pictures.

## Fixed

- The wallpaper count is now the same in the header, on the Wallpaper page and
  in `one-mk wallpaper`.
- Switching from one video to another on GNOME no longer stops the new video
  from starting.
- A screen too large to draw on is skipped. The wallpaper keeps playing on
  your other screens.
