# oneMK 0.1.20: the Night window, live wallpaper, and everything from the window

The name is now **oneMK**, with a new mark: a pointer cut by a screen's edge,
its tip already across and lit. The command you type stays `one-mk`.

## A new window

- **Night design.** Solid dark surfaces, a compact sidebar with a shortcut for
  each page (⌘1 Desk, ⌘2 Wallpaper, ⌘3 Clipboard & files, ⌘4 Keys & mouse,
  ⌘, Settings; Ctrl on Windows and Linux), and glass only where something
  floats.
- **⌘K finds anything.** Every page, every action (switch to a computer, send
  or get the clipboard, lock every screen, type on every computer, pair, start
  or stop, pause the wallpaper) and every setting, from a few letters.
- **Desk** has two views: Computers, and Arrange (where the old Layout page
  went). Health opens from the status line at the bottom of the sidebar.
- **The menu-bar menu** can now get the clipboard from a computer, pause the
  wallpaper, and uses the window's words ("Type on every computer").
- Settings, Keys & mouse and Clipboard & files were redone in the same style;
  the commands editor is now one compact block per event.

## New

- **Live wallpaper across every screen of every computer.** Choose one video
  (or a picture) and it plays as one picture across all your monitors, on all
  your computers, in sync. Wallpaper (⌘2) shows each screen with its part of
  the picture, and each computer says whether it is preparing, playing or what
  went wrong.
  - One decode per computer, hardware decoding where the system offers it.
    Paused while every screen is covered, on battery (if you want), in Low
    Power Mode or battery saver, while locked and while the screens sleep.
    Nothing runs while it is off.
  - A video much larger than your screens is shrunk once, with the computer's
    own hardware encoder, when you choose it.
  - A picture is set as each computer's ordinary wallpaper (no player runs),
    and your previous wallpaper comes back when you turn it off.
  - Update every computer that shows the wallpaper together: older versions
    don't take part.
- **Letters, not keys.** Keys & mouse → Typing: "Letters" types the
  characters printed on your keys on the other computer, even when its keyboard
  layout is different. "Auto" does so only when the layouts differ. Mac and
  Windows computers receive letters; Linux computers receive keys.
- **Remap keys on this computer too.** Keys & mouse → "Also on this computer"
  applies your key and button rules locally as well (macOS and Windows). Off by
  default. Your keyboard is put back if oneMK stops or crashes.
- **Wi-Fi profiles on macOS and Windows.** A saved layout can switch by itself
  when you join a Wi-Fi network.
- **Updates in place.** Signed updates download and install from the window
  (Settings → Updates); on macOS the app is swapped in one step, so an
  interrupted update never leaves you without one.

## Fixes

- A computer that types letters no longer looks like a wallpaper player to
  others (two features had claimed the same capability).
- Health speaks plainly and offers the fix for each problem.
- Pictures for the wallpaper are decoded in the separate wallpaper helper, never
  in the background service, so a picture from another computer can't reach the
  service's image decoder.

## Not verified yet

- **macOS and Windows** have only been compile-checked and unit-tested for
  this release's new parts: live wallpaper, letters typing, local remapping,
  Wi-Fi profiles and in-place updates have not yet run on a Mac or a Windows
  PC. The checklists are in `docs/LIVE-WALLPAPER.md`, `docs/KEYBOARD-LAYOUT.md`,
  `docs/LOCAL-REMAP.md`, `docs/WIFI-PROFILES.md` and `docs/UPDATES.md`.
- **Wallpaper cost.** Paused and covered, the player measured 0% CPU and no
  wakeups on Linux. Playing, its cost on Mac and Windows hardware decoders is
  not measured yet; on Linux without hardware decoding a 4K video costs a
  noticeable share of a core.
- **Wayland**: live video wallpaper is not available on Wayland desktops yet
  (pictures work on GNOME).
