One mouse. One keyboard. Every computer.

Push the pointer off the edge of one screen and it lands on the next computer. Your keyboard, clipboard and files follow it. Free and open source, for Linux, macOS and Windows.

    Set up in about a minute.

    Install oneMK on each computer. The window walks you through the rest; the same steps work from a terminal.

    1. Pair with six digits

      Choose Pair another computer on both. Each shows the same six-digit code; confirm it on both and they trust each other from then on. No IP addresses, no certificates to copy.

      one-mk pair

    2. Arrange your screens

      Drag each computer to where it really stands. Leave it anywhere along a side, or line the edges up to the pixel so the pointer crosses only where the screens touch.

      one-mk layout "MacBook Air" left

    3. Push past the edge

      The pointer leaves one screen and appears on the next computer at the same height. Ctrl Alt H brings it home, and Ctrl Alt Shift Esc always does.

    4. Everything follows

      Your keyboard types where the pointer is. Copy on one computer and paste on another: text, rich text and pictures. Drop files on a computer to send them.

      one-mk send photos/ --to "MacBook Air"

    Every computer, one desk.

    The parts you would expect from one computer with many screens, and a window that shows you what is going on.

    Screens lined up to the pixel

    Drag screens on a flat plan, nudge them with the arrow keys or type an exact X and Y. Several computers can share one side, and layouts can switch by themselves when you join a Wi-Fi network.

    Copy here, paste there

    Text, rich text and images follow the pointer, up to 25 MB by default and 256 MB if you raise it. Copies a password manager marks as sensitive stay where they are.

    Files that arrive whole

    Drop files on a computer in the window, use Send to in your file manager, or one-mk send. Transfers resume after a dropped connection, are checked with BLAKE3 and land in Downloads/one-mk.

    One wallpaper across every screen

    A picture or a video, sliced across all your monitors on all your computers as if they were one wide display. Stable for video on Linux X11 and for pictures on GNOME; elsewhere it is Experimental

    Health that explains itself

    Health checks the program, the port, discovery, the firewall and permissions, and names the problem and the fix in plain words. It only reads; it never changes your settings.

    Everything is a search away

    Ctrl K (⌘ K on a Mac) opens a palette that goes to any page, setting or computer.

    Shortcuts that stay out of the way

    • CtrlAlt1…9Jump to a computer
    • CtrlAltHBack to this one
    • CtrlAltPKeep the pointer here
    • CtrlAltBType on every computer

    Ctrl and Cmd swap between a Mac and a PC by default. On Windows the jump and broadcast shortcuts add Shift.

    Light and dark

    The window follows your computer’s appearance and cross-fades when it changes. So does this page.

    Change a key. Watch it change.

    Keys & mouse draws your keyboard and mouse in 3D. Click a key, choose what it should do, and every changed key is marked on the drawing.

    • Tap and hold, chords, sequences and layers, with a 200 ms hold by default.
    • Rules for every computer, or only for Macs, one computer or one app.
    • Mouse buttons, pointer speed and scrolling, per computer.
    • Rules change what is sent to other computers; your own typing stays as it is.

    Rules for one particular keyboard or mouse work on Linux X11 only. Typing the letters printed on your keys toward Windows and Mac computers is Experimental

    Your computers talk to each other. No one else.

    There is no server and no account. Paired computers connect directly on your network, and every connection is encrypted and checked.

    Same code on both screens: confirm on both.
    A code you compare
    Pairing uses a commit-then-reveal six-digit code, like pairing a Bluetooth headset. You check that both screens show the same digits and confirm on both.
    Mutual TLS 1.3 over QUIC
    Each computer has its own key and certificate. Both sides check the other’s fingerprint on every connection, and only paired computers get in.
    Signed updates that ask first
    Every release lists its files with sizes and SHA-256 sums in an Ed25519-signed list. oneMK checks it, refuses downgrades, and asks before installing.
    One port, one check a day
    oneMK listens on UDP port 24900 and uses mDNS to find your computers. Outside your network it asks GitHub once a day whether there is an update, and you can switch that off.

    oneMK has not had an outside security review yet. The security model says plainly what it protects and what it does not, and SECURITY.md says how to report a problem.

    Where it runs, honestly.

    oneMK is young. Everything below is built and tested on every change, but only one setup has been used end to end on real hardware so far.

    • Desktop notifications on Windows

    Check what you downloaded

    Every release lists each file’s SHA-256 in SHA256SUMS (also in the Ed25519-signed update-manifest.json). In the folder with your download:

    sha256sum -c --ignore-missing SHA256SUMS

    Questions

    Is oneMK free?

    Yes. It is open source under your choice of the MIT or Apache-2.0 licence, with no paid tier, no account and no sign-up.

    Do my computers need the internet?

    No. They need to be on the same network and able to reach each other: the firewall must allow UDP port 24900, and mDNS (UDP 5353) for finding each other. If discovery is blocked you can connect by address with one-mk pair --connect. The internet is only used for the daily update check, which you can switch off.

    What gets shared, exactly?

    The keyboard and mouse go to the computer the pointer is on. The clipboard shares text, rich text and images. Files are sent on purpose: drop them on a computer in the window, use Send to in your file manager, or run one-mk send. oneMK does not share screens.

    What if the pointer gets stuck on another computer?

    Ctrl Alt H brings it back, and Ctrl Alt Shift Esc always does; no rule can change that one. Held keys are released when the pointer leaves, a computer disconnects, or nothing arrives for 750 ms. On Wayland, use the shortcut or one-mk takeback to take a computer back.

    Can I use it with a Mac and a Linux PC together?

    Yes, any mix of Linux, macOS and Windows can pair. Ctrl and Cmd swap between a Mac and a PC by default. macOS and Windows support is experimental: it is built and tested on every change but has not been run end to end on real hardware yet.

    Does it work at the Windows sign-in screen?

    No. oneMK runs as your user and not as a Windows service, so it cannot reach the lock screen, the sign-in screen or UAC prompts. That is a deliberate choice.

    How do updates work?

    By default oneMK checks for a new release once a day and asks before installing it. It verifies the Ed25519 signature and the file’s checksum first, and refuses older versions. You can also run one-mk update, or switch the check off in Settings.

    Can I drive it from a terminal?

    Everything the window does is a command: one-mk pair, one-mk layout, one-mk send, one-mk switch, one-mk doctor and more, listed in the command reference.
