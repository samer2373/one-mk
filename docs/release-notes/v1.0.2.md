# oneMK 1.0.2: links work, and a wallpaper retry that works

A small fix on top of 1.0.1.

## What is new

- **Links in the app open again.** The "Visit bigfootjo.com" button in Settings → General → About did nothing, and so did the 3D-mouse credit link, the "download the update" link, and the Mac "open Firewall settings" and "open Accessibility settings" fixes. The window was built without the part of its toolkit that opens web links, and failed silently. They now open through your system's own opener, and a test keeps it that way.
- **"Try again" after a failed wallpaper change no longer fails with "UDP port 24900 is busy".** The button ran a bare `one-mk`, which started a second oneMK next to the running one. It now sends the same wallpaper command again, and the window refuses to run `one-mk` with nothing to do.
- **The website's 3D keyboard fits its base.** One key hung off the edge of the board on https://samer2373.github.io/one-mk/. This changes the website only, not the app.

Nothing about pairing, sharing, updates or the service changed.
