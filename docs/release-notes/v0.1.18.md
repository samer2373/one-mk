# one·mk 0.1.18 — test and CI hardening on top of 0.1.17

No change to how one·mk behaves. This release carries everything on `main` since
0.1.17: fixes to the automated tests so they pass reliably on Linux, Windows and
macOS. The 0.1.17 notes still describe the user-visible changes (the audit fixes
and the 0.1.15 feature batch).

## Test and CI fixes

- The X11 tests start their own private X server on a free high display number,
  wait until it answers, and no longer race when run in parallel.
- Windows tests: the default shortcut, the broadcast stop chord, and the command
  line and environment the daemon tests use.
- macOS tests: shorter daemon names so socket paths stay under the 104-byte limit;
  the push test and the hotkey label match the platform.
- CI runs the whole workspace with `--no-fail-fast` and backtraces on, so one
  failure shows every other failure in the same run.

## Not in this release

- **There is still no live wallpaper.** It stays experimental and off by default.
- **Typing characters that are not on the receiving keyboard layout** stays off.
- **Automatic updates** stay off until an update signing key is set (see
  `docs/UPDATES.md`).
- Known flake: the X11 test `devices_are_listed_and_input_says_which_one` can fail
  about one run in eight.
