# oneMK 1.2.0: use it on one computer

Pairing is optional now. Some things need no second computer, and oneMK says so.

## What is new

- **The Desk offers what works on this computer alone.** With nothing paired, under "Pair your first computer" there is a line "Or use oneMK on this computer alone" with buttons for Wallpaper, Clipboard history and, on a Mac or Windows PC, Change keys.
- **Your first key rule applies on this computer.** With no other computer paired and no key rules yet, the first change you make (a quick setup such as Caps Lock as Esc/Ctrl, or a single key) also switches on "Also on this computer", so it takes effect right away instead of waiting for a second computer. It is still experimental on Mac and Windows; Ctrl + Alt + Shift + Esc turns it off.
- **Keys & mouse says what this computer can do.** The card is called "On this computer" and, with nothing paired, says you don't need a second computer. On Linux it says plainly that changing this computer's own keys needs macOS or Windows for now, and that the rules you make work on the computers you pair.
- **Wallpaper and clipboard history** already worked with one computer; the Desk now points to them.

Nothing about pairing, sharing, updates or the service changed.
