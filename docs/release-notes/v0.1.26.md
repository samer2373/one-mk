# oneMK 0.1.26: in-app updates work on the Mac and on Linux

## Fixed

- **"The update didn't finish: the app's security check failed" on the Mac.**
  The check that confirms an update comes from the same publisher asked
  `codesign` for its requirement in a form it reads as a file name, so it
  failed for every update, even a genuine one, and nothing was ever replaced.
  It now asks the right way. If a check still fails, the message names which
  app failed and the reason is written to the log.
- **"The update didn't finish: No such file or directory" on Linux.** The
  update was installed, but the app then tried to reopen itself from the file
  the update had just replaced, which Linux no longer lists under that name.
  It now reopens the new program at the same place.

On the Mac the old version can't install this one, so install 0.1.26 once by
hand (open the disk image and drag oneMK to Applications). On Linux the
update itself still installs; just open oneMK again afterwards. Updates from
then on happen inside the app.
