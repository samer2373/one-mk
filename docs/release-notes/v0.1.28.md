# oneMK 0.1.28: Mac updates install again

## Fixed

- Updating on a Mac no longer fails with "cannot access update files or the update server". The check that starts the new app before installing it left a file inside the new app, which made macOS stop it as damaged (and show a "damaged, move to Trash" message). The file now goes beside the app, and the error message includes the real reason when something else goes wrong.

If you are on 0.1.26 or 0.1.27 and the update fails, install 0.1.28 once from the download page; updates work from there.
